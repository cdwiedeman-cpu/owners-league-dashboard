Setting Bob Up

Everything it takes to give Bob his own way in to the league, in the order to do it. It is much shorter than it used to be.

Before You Start

One thing, and you can look it up at any time: Bob's sign-in code, off the Access List tab of the dashboard.

There is no password to hand over and no authenticator to set up. The league used to run on a shared Google account and that account was disabled without warning, so it does not work that way any more. Bob's code is his alone and yours is yours.

Send the code to him on its own. Never send it in a message that reaches more than one person.

Bob needs one thing, and it takes about a minute.

Give Him His Code

  1. Open the Access List tab on the dashboard.
  2. Find his row. His code is in the Code column.
  3. Email or text it to him on its own. Never put it in a group message.
  4. He opens the dashboard, goes to Trades, and types it in.

He is then signed in on that device for good. He does the same on any other phone or computer he uses, with the same code.

What He Can Do Once He Is In

His row says commissioner, so he sees everything you see. He can settle a week, enter a trade for any seat, read every code, and retire somebody's sign-in.

The league will not let either of you stand down the last commissioner. There is no way for the two of you to lock yourselves out.

There Is Nothing Else to Set Up

No shared account, no password, no authenticator app, and no spreadsheet. Bob's code is his own, yours is yours, and the league works out who is asking from the code itself.

This used to take an evening and a written-down password. It does not any more.

If He Loses His Phone

Open the Access List, press Retire and Issue a New Code on his row, and read him the new code. Every device he was signed in on is turned away straight away. Your own sign-in is not touched.

Bob has full access once he has one thing: his own six character code. Everything else that used to be on this page was there to share one account between two people, and there is no shared account any more.
