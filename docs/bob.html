Setting Bob Up

Everything it takes to give Bob his own way in to the league Google account, in the order to do it. Read it off a phone while you work through it.

Before You Start

Casey needs two things written on paper, and neither can be looked up later.

  • The password for realityfootballcommish@gmail.com.
  • The authenticator setup key, the string of letters and numbers from the screen where the authenticator was set up.

Both are worth the same as each other. Hand them over on paper or out loud, and never in an email.

If the key was never written down, go to If the Key Does Not Work, Start Over and do that first.

Everything up to this point Casey does on his own. This is the part that needs both of you, and it takes about fifteen minutes. Casey brings the password and the setup key, both written on paper. Work straight down this list.

1. Bob Installs Google Authenticator

  1. Open the App Store on an iPhone, or the Play Store on an Android phone.
  2. Search for Google Authenticator. The one you want is published by Google LLC, and its icon is a grey padlock on a white background. Several other apps have similar names.
  3. Install it and open it.
  4. The first screen is a welcome screen. Tap Get started.
  5. It then offers to sign in with a Google account. Bob signs in with his own personal Google account, which keeps a backup of his codes. If he has no Google account, or does not want one involved, tap Use Authenticator without an account instead. Either choice works. Do not sign the app in to the league account.

He now has an empty screen that says he has no codes yet.

2. Bob Adds the League Account by Typing the Key

All of this happens on Bob’s phone, inside Google Authenticator. He never sees a QR code and he never opens a Google web page for this. The QR code belongs to the setup Casey already finished on his own computer, and it is gone. The key is what replaces it.

  1. Tap the + button. On Android it sits at the bottom right of the screen. On an iPhone it sits at the top right.
  2. Two choices appear: Scan a QR code and Enter a setup key. Tap Enter a setup key.
  3. A form appears with three parts.
    • Account name or Account: type realityfootballcommish. This is only a label, so any name Bob will recognise is fine.
    • Your key or Key: type in the string Casey brought. Spaces and capitals do not matter, and Google Authenticator ignores them.
    • Type of key: leave it on Time based. Do not change it to Counter based.
  4. Tap Add.

An entry appears showing six digits and a shrinking circle beside them. The digits change every thirty seconds.

3. Check the Two Phones Agree

To see a code on either phone, open Google Authenticator. The entry named realityfootballcommish shows six digits and a shrinking circle. That is the code. Nothing has to be tapped or unlocked to read it.

Together in one room: hold the phones side by side and look at both entries. They must show the same six digits at the same moment.

On the phone or on a video call: do not try to read codes to each other. A code lives thirty seconds and you will spend the call chasing it. Have Bob sign in instead. Go straight to part 4 and part 5. If Google accepts his code, the key is right, and that is a better proof than any comparison. If Google says the code is wrong, the key is wrong.

If it is wrong, delete the entry on Bob’s phone and do part 2 again. Read the key out character by character, saying “capital” or “lower case” for each letter.

If a carefully typed key still fails, check the clock. Both phones need the date and time set automatically, in the phone’s own date and time settings. These codes are built from the current time, so a phone with a wrong clock produces wrong codes.

4. Casey Hands Over the Password

Casey gives Bob the password for realityfootballcommish@gmail.com, on paper or out loud. Bob puts it wherever he keeps his own passwords. It does not go in an email.

5. Bob Signs In on His Own Laptop or Phone

  1. Bob opens a browser and goes to gmail.com.
  2. If a different account is already signed in, click the picture at the top right and choose Add another account.
  3. He types realityfootballcommish@gmail.com and the password.
  4. Google asks for a six digit code. Bob reads it off his own Google Authenticator and types it in. If Google offers a different way first, choose Try another way, then Get a verification code from the Google Authenticator app.
  5. If Google offers to remember the device, say yes. That stops it asking on that device every time.

He is in. This is the moment the whole thing is proved, so do not skip it.

6. Bob Adds a Passkey on That Device

This is what stops Google asking him for codes on the device he uses most.

  1. Still signed in as the league account, go to myaccount.google.com.
  2. Open Security.
  3. Find How you sign in to Google and open Passkeys and security keys.
  4. Tap Create a passkey, then Continue.
  5. The device asks for his fingerprint, his face, or the screen lock code. That is it.

From now on that device opens the league account with his fingerprint or face. The code app is only needed on a device that has no passkey.

7. The Two of You Look at the Spreadsheet

  1. Open RFL Trades and go to the Access tab.
  2. Check that Bob’s row and Casey’s row both read commissioner in the Role column. Every other row reads owner.
  3. Go down the Email column together. Fill in every address Bob knows.
  4. Write down who is still missing, and agree who is chasing them.

Nobody can sign in to the RFL application until their own address is in that column, so this is the item that decides when the owners can start using it.

What Full Access Means

Bob has full access once he has four things. Nothing else is needed, because the spreadsheet and the emails live inside the account.

  1. The address, realityfootballcommish@gmail.com.
  2. The password.
  3. An authenticator app showing the same codes as Casey’s.
  4. A passkey on the device he uses most.

Do not change the recovery phone number to Bob’s. Recovery is for getting a locked account back, it is not the everyday sign-in, and moving it away from Casey helps nobody.

If the Key Does Not Work, Start Over

There is no way to read the key back out of Google. If it was mistyped, or never written down, the only fix is to set the authenticator up again. That produces a new key and kills the old one, so whoever already had a working code has to redo it too.

Casey does this on a computer, signed in to the league account.

  1. Go to myaccount.google.com and open Security.
  2. Open 2-Step Verification. Google asks for the password again.
  3. Find Authenticator in the list and choose Change authenticator app.
  4. A QR code appears. Stay on this screen. Click Can't scan it? beside it and write down the string of letters and numbers. This is the only screen it ever appears on.
  5. Click back to the QR code, open Google Authenticator on Casey’s phone, tap +, tap Scan a QR code, and scan it.
  6. Type the six digits his phone shows into the computer to finish.
  7. Delete the old entry from Casey’s phone. It is dead now, and two entries that look alike with only one working is a bad thing to own.
  8. Give Bob the new string, and he does part 2 again.

Check the key before you trust it. On Casey’s phone, add a second entry called test using Enter a setup key and the string he just wrote down. If test and the real entry show the same six digits, the string is right. Delete test afterwards and keep the real one.

Bob has full access once he has four things: the address, the password, an authenticator app showing the same codes as Casey’s, and a passkey on the device he uses most.
