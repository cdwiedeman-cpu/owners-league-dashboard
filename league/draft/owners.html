Sleepers & Surprises

Save This Draft

You do not need this to carry on where you left off. On this device the page remembers the draft by itself — close the tab, reopen it, and press Resume.

Save is for the other two things: moving the draft to your other device, and keeping a copy somewhere safe in case this one loses it.

To move the draft to your other device: press Copy the draft here, paste it into a note or an email to yourself, then on the other device open the dashboard, press Load, and paste it in. That works from any device to any other device. A downloaded file holds exactly the same thing and loads the same way.

Why can't it save straight into my folder? Because no web page can write to a folder on an iPad — Safari has never supported the API that would allow it, on any version. The server app only reads that folder in order to serve this page; there is no way back along that road. A download and the share sheet are the only routes out, and both put the file where the system decides, not where the page asks.

Load a Saved Draft

Paste the text you copied from your other device, or open a file you downloaded. Both carry the same draft. A file saved by a commissioner holds all three divisions, and you choose which of them to put back.

If you just want to carry on where you left off on this device, you do not need either: close this, reload the page, and press Resume.
